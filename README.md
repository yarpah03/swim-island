# Плавательный остров ВИП

Прототип мини-приложения для телеграма.

## Что где лежит

| Файл | Что это |
|---|---|
| `index.html` | Интерфейс: разметка, стили, разделы, уроки с нуля |
| `trenirovki.js` | Готовые тренировки на воде — только данные |
| `obuchenie.js` | Упражнения по стилям, ошибки, старты, повороты |
| `hero.jpg` | Фон главного экрана, 1600×900 |
| `hero-mobile.jpg` | То же для телефонов, подгружается сам |
| `mark.svg` | Логотип на прозрачном фоне |

Все три файла нужны вместе: без `trenirovki.js` или `obuchenie.js`
сайт откроется, но соответствующие разделы будут пустыми.

## Как выложить в первый раз

1. Заходите на github.com, жмёте **New repository**
2. Имя — например `swim-island`, тип **Public** (иначе не заработает
   бесплатный хостинг, см. ниже)
3. На странице пустого репозитория — **uploading an existing file**
4. Перетаскиваете в окно браузера содержимое этой папки,
   **кроме папки с видео** — она тяжёлая и через браузер не залезет.
   Про видео есть отдельный раздел ниже.
5. Внизу пишете, что меняли, и жмёте **Commit changes**

Ничего устанавливать не нужно, всё делается в браузере.

## Как дать доступ второму человеку

Settings → Collaborators → Add people → его логин на GitHub.
Он получит письмо, примет приглашение и сможет править файлы наравне с вами.

## Как включить сайт по ссылке

Settings → Pages → Source: **Deploy from a branch** → ветка `main`, папка `/ (root)` → Save.

Через минуту-две сайт будет доступен по адресу вида
`https://ваш-логин.github.io/swim-island/`

Эту ссылку и скармливаете телеграму как мини-приложение — через BotFather
или через кнопку веб-приложения в вашем конструкторе бота.

Важно: **GitHub Pages работает только на публичных репозиториях** на бесплатном тарифе.
Если репозиторий приватный, Pages потребует платный план. Для прототипа проще
сделать репозиторий публичным — там нет ничего секретного, кроме вёрстки.
Платный контент всё равно будет закрываться проверкой подписки на сервере.

## Как править вдвоём и не мешать друг другу

Правило одно: **не редактируйте один и тот же файл одновременно**.

Теперь это проще, потому что файлов три: `index.html` (интерфейс,
уроки, тексты разделов), `trenirovki.js` (тренировки на воде)
и `obuchenie.js` (упражнения, ошибки, старты, повороты).
Разошлись по разным файлам — и друг другу не мешаете.

Если оба лезете в один файл — договоритесь голосом и перед началом
загляните во вкладку **Commits**: не залил ли партнёр правки минуту назад.
Тот, кто сохранит вторым, затрёт работу первого.

## Про видео

Сейчас в папке лежит 94 мегабайта роликов. **Это временно, и через браузер
такой объём заливается плохо.** Видео должно жить на Kinescope, а не в git.

### Как перевести видео на Kinescope

1. Зарегистрируйтесь на kinescope.io, создайте проект.
2. Залейте все шесть роликов из папки «Баттерфляй с нуля — видео».
   Заливка идёт частями, большие файлы не обрываются.
3. Дождитесь, пока каждый ролик обработается — статус станет «Готово».
4. Откройте ролик и скопируйте его **ID**: в адресе плеера
   `https://kinescope.io/embed/202589431` это цифры в конце.
5. Откройте `index.html`, найдите в начале блок `const KINESCOPE = {`
   и впишите ID в кавычки напротив нужного файла:

```js
const KINESCOPE = {
  "Баттерфляй_01_Ноги_с_доской.mp4":        "202589431",
  "Баттерфляй_02_Ноги_без_доски.mp4":       "202589432",
  ...
};
```

Пока строка пустая — играет локальный файл. Как только вписан ID —
на его месте встаёт плеер Kinescope. Можно переносить по одному ролику.

6. Когда все шесть переведены: раскомментируйте последнюю строку в
   `.gitignore` и удалите папку с видео из репозитория.

### Настройки в Kinescope

- **Разрешённые домены** — впишите адрес сайта. Тогда чужой сайт
  с вашим кодом плеера видео не покажет.
- Плеер запускается сам, без звука. Звук включается кнопкой в плеере.
- Одновременно звучит только один ролик: остальные встают на паузу сами.

## Где что менять в index.html

Всё содержимое приложения лежит в объекте `T` в конце файла.
Разметку трогать не нужно — достаточно добавить или поправить текст там.

- `T.home` — главный экран
- `T.s1` … `T.s7` — семь разделов
- `T.bt0` — урок «Баттерфляй с нуля», образец для остальных стилей
- `PARENT` — кто чей родитель, нужен для навигации назад

Новый урок делается копией `T.bt0`: меняете тексты, номера и имена видео,
добавляете строчку в `PARENT` и ссылку в списке нужного раздела.
