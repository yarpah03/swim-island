# Плавательный остров: материалы, новости и VIP

Действующий бот: https://t.me/swim_island_entry_bot

Бот открывает меню с фотообложками: бесплатные материалы, описание клуба, тарифы, оформление подписки, вход в приложение, новости и помощь. Приветствие объясняет, что бот присылает новости. Команда /stop отключает их; повторный /start не отменяет отписку.

## Для Ярослава и Макара

В главном меню тренера появляется кнопка «Управление ботом». Также доступна команда /admin. Права проверяются по подтверждённым числовым Telegram ID в BOT_ADMIN_IDS, а не по изменяемому username.

- **Добавить материал:** раздел → название → описание → PDF, видео или HTTPS-ссылка → фотообложка → предпросмотр → публикация. Рассылка при публикации не отправляется.
- **Каталог:** просмотр, скрытие и возврат материалов. Большие каталоги разбиты на страницы.
- **Новая рассылка:** одно сообщение с текстом, фото, видео или файлом → предпросмотр → подтверждение отправки. До подтверждения получатели ничего не видят.
- **Рассылки и статистика:** число доставленных сообщений и оставшиеся получатели. Отправка идёт пакетами до 200 получателей. При большой аудитории или паузе Telegram бот предлагает продолжить. Отписавшиеся исключаются, заблокировавшие бота удаляются из активной доставки. Повторное нажатие не создаёт новую рассылку. Неопределённый результат сети не переотправляется автоматически.
- /cancel отменяет редактирование черновика.

Выпуски новостей сохраняются в D1 с Telegram file_id и форматированием; архив не зависит от сохранности исходного сообщения администратора.

## Контент и платежи

Стартовый бесплатный каталог: «Брасс с нуля: 8 тренировок», «Перед тренировкой в бассейне», «Как работать над техникой». Видеоурок пока не опубликован: каталог предлагает начать с PDF. Готовый ролик можно добавить через управление.

Тарифы читаются из официального API Tribute для VIP-подписки 228039. При недоступности API показаны последние подтверждённые цены с соответствующей подписью. Оплата выполняется в официальном Tribute по действующей ссылке https://t.me/tribute/app?startapp=sXk3; бот не принимает данные карт и сам не выдаёт доступ.

Сохраняется отдельный вход ?start=test100 с существующим TRIBUTE_TEST_CHECKOUT_URL; он не показан в публичном меню. Итоговая стоимость и условия проверяются в Tribute.

Платная подписка, пробный режим и истёкший срок различаются при проверке статуса. Доступ в приложение и платные PDF по-прежнему контролирует приложение. Бесплатные PDF этого бота — отдельные заранее одобренные материалы.

Для сайта пока нужен существующий веб-аккаунт или подключение через тренера: оплата в Tribute сама по себе не создаёт веб-логин. Интерфейс сообщает об этом явно.

## Сборка и публикация

Node.js 22.17+; отдельная D1 swim-island-entry, binding BOT_DB. База чатов приложения не изменяется.

1. В этой папке выполнить npm install и npm test.
2. Применить schema.sql к отдельной D1 и внести стартовые записи SEED из catalog.mjs, не перезаписывая добавленные материалы.
3. В production Cloudflare Pages swim-island-entry-bot сохранить Secret: TELEGRAM_BOT_TOKEN, TELEGRAM_WEBHOOK_SECRET, TRIBUTE_API_KEY, BOT_CONTROL_TOKEN. Сохранить переменные BOT_ADMIN_IDS и TRIBUTE_VIP_SUBSCRIPTION_IDS. Существующий TRIBUTE_TEST_CHECKOUT_URL оставить.
4. Выполнить npm run build. Сборщик копирует фото из корня репозитория и получает бесплатные PDF из опубликованного каталога, проверяя SHA-256 по free-assets.json. Для локальной сборки можно передать BOT_FREE_MATERIALS с папкой трёх бесплатных PDF.
5. Выполнить wrangler pages deploy ../dist/bot --project-name swim-island-entry-bot --branch main.

Секреты не входят в исходники и не передаются в URL. Подпись Telegram-вебхука проверяется до обработки JSON. Маршрут /control/setup доступен только с отдельным Bearer-токеном; перед изменением профиля сверяет username swim_island_entry_bot, настраивает команды и аватарку, сохраняет существующий корректный вебхук. Маршрут /control/inspect позволяет проверить состояние без отправки сообщений подписчикам. Настройка не запускает рассылку и не выполняет покупок.

Проверки: node --test bot.test.mjs, /health, реальная проверка аккаунта, вебхука, команд и аватара через /control/inspect. Меню, выдача файлов, права тренеров, черновики, отписка и защита от дублей проверяются с локальной SQLite и имитацией Telegram API. Реальных платёжных списаний и рассылки по клиентам тесты не делают.
